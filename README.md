# 英雄传说：命之轨迹 TRPG — 角色卡创建工具

向导式建卡工具：16 步完成角色创建，自动计算全部数值，支持在线使用与导出。

## 在线使用

https://clark1091.github.io/trails-trpg-character-sheet/

## 功能

- 向导式建卡：命位 / 属性 / 元素与武艺相性 / 天赋 / 技能 / 战技 / 装备 / 导力器 / 机甲 / 关系网
- 自动计算：属性、资源（HP/耐久/EP）、检定奖励速查（含场景加值）、武器 / 护甲 / 结晶回路 / 机甲 / 载具
- 完成页角色卡：右侧快速导航、导出长图 / PDF / JSON 存档 / 复制文本
- 完全离线可用：纯静态、无后端，数据保存在浏览器本地
